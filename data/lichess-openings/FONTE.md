# Fonte desta pasta

Arquivos `a.tsv` a `e.tsv` copiados de https://github.com/lichess-org/chess-openings
em 2026-11-15. Colunas: `eco` (código ECO), `name` (nome da abertura), `pgn` (lances).

Licença: segundo o README do repositório, o conjunto de dados está em domínio
público e, no que couber direito autoral, foi liberado sob CC0 1.0.

Não edite estes arquivos. Eles são a referência que os testes usam para confirmar
que as aberturas do app são reais.
